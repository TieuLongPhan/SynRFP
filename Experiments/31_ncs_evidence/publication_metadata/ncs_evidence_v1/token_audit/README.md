# Bounded change/context diagnostic

This label-blind diagnostic samples at most 128 original rows from each of 24 frozen source pools, retains selected source refusals, and fits no models. Byte-identical source populations are aliases. Selection uses original row identities and positions, never labels or measured performance.

`token_information.csv` reports full-count cancellation and shared-context statistics. `observed_equalities.csv` separates equal full-count signatures, equal support signatures, and equal 2048-bit parity sketches within each finite sample. Conditional rates use the explicitly reported different-signature pair denominators. They are not estimates of exhaustive chemical collisions.

For existing hashed token IDs, D=P-R, U=P+R and S=min(R,P) obey U=abs(D)+2S. The full-count pairs (D,U) and (D,S) are reversible descriptions of the same R,P counts. Support reduction discards magnitudes; sketching and the split 1024+1024 bit budgets can discard more information. Original roles means shared local token environments, not atom retention or condition roles. Native token IDs are hashes, and neither token nor sketch equality certifies chemical identity.

Rows with original eligibility or parsing refusals remain in sampled-row and refusal totals, but never contribute zero placeholders to equality measurements. Local row receipts contain no reaction strings or targets. The audit supplies descriptive evidence only, with no predictive superiority or SOTA claim.
