# Ten-seed Path clustering challenger

The latest user steering keeps corrected Morgan study43 first, permits one
additional CPU lane when resource headroom permits, and defers classification
MLP/GPU promotion. Study44 freezes the explicitly requested unchanged preset
`synrfp-path-r2-b2048-parity-delta` as a provisional challenger. It is not an
automatically selected factorial winner. Existing shared-WL main results and
all historical studies remain unchanged.

The new queue admits one worker on CPU18 with 1 CPU equivalent and 12 GiB RAM,
using the original `synrfp` Python environment and hidden CUDA. Preparation has
the same limits; final reporting has 1 CPU/8 GiB. It scores the 12 full known-K
main endpoints, both original populations and 10 matched initializations:
240 logical candidate cells, with 200 fits and 40 verified identical-population
copies. Five competing fingerprints reuse 1,200 audited native cells. These
are initialization seeds, not CV folds. Class-count-blind study41 remains a
separate protocol.

Initial admission requires executed controller/scientific/report controls,
source hashes, an explicit user-intent receipt and a source-bound root review.
`ROOT_REVIEW.json` allows only `prepare` and `clustering`, sets
`declared_path_challenger=true`, `study43_priority_preserved=true`, and
`GPU0_reserved=true`, and binds the exact intent and all three code-readiness
receipts. Future decisions and the prepared matched plan get separate immutable
hash seals and execution receipts. Scientific readiness binds the executed
numerical estimator/replay controls to the unchanged original main recipe.

Resource admission counts finite cgroup CPU/RAM caps for all research services,
retains the 85% ceiling, study41's stricter legacy pending-stage reserve, its
35% available-RAM launch floor, and at least 40 GiB free on both HOME and the
resolved artifact filesystem. Every unfinished study43 lane not already live
gets a reserved future CPU/RAM allocation. A resource wait does not indicate a
scientific failure. Existing Morgan, reference and kNN governors are never
stopped, modified or signaled. A separately reviewed governor-only41 pause
can release41's pending reserve while every live worker remains accounted.
Only after both43 and44 exact report closures and all44 services exit does
this controller restore that same attested41 governor. This controller has no
GPU job or lease capability.

Only owned study44 clustering invocations may receive SIGUSR1; they finish
their current cell and retain artifacts before yielding. Each retry uses a new
invocation ID; old directories, failures, assignments and models are preserved.
OOM, CUDA, integrity and environment errors latch, with at most three other
failed generations. A source change fails closed. Only exact keyed shard and
retained artifact closure permits final reporting. The clustering report may
close independently of the deferred classification code.

The automatic six-source-family decision policy is implemented and tested for
later use after complete corrected study43 reports. It does not run in this
controller. It averages original repeats within endpoints, endpoints within
each of the six source families, and families equally. The primary ordering is
mean MCC for classification or AMI for clustering, followed by mean family
rank, normalized regret, worst family rank and configuration ID. All such
selection is exploratory, and MLP-based selection does not establish a kNN
optimum. A new explicit root review is required before any such promotion or
classification dispatch.

No service installation, worker launch, model deletion, old-cache mutation or
Git publication is performed by code preparation or controller preflight.
