# E1 context attribution results

The completed run contains 720 fits on the pinned Buchwald–Hartwig and Suzuki tables. The source revision and input hashes are recorded in the manifest.

The prespecified Buchwald–Hartwig comparison measures the difference in grouped out-of-fold R² between pooled context and rehashed delta at equal width, with the same condition indicators supplied to both arms. The difference was +0.1400, with a 95% paired group-bootstrap interval of [+0.0031, +0.3189]. The interval describes variation across the held-out groups conditional on the saved fits.

The release contains per-fit scores, paired contrasts, grouped out-of-fold summaries and provenance. Row-level inputs, split memberships and predictions are retained on the workstation.
