# Schneider and USPTO-50K class names

Both Schneider names used in the figures are correct. Class index **10** maps to **1.7.6, Methyl esterification**. Index **25** maps to **2.6.3, Fischer-Speier esterification**. All 50 names agree verbatim between the original Schneider supporting archive and the pinned RXNFP dictionary. [Schneider supporting archive](https://doi.org/10.1021/ci5006614.s002) · [Pinned RXNFP name dictionary](https://github.com/rxn4chemistry/rxnfp/blob/6fd48f4927c2178555cc5d71dbfb225fb178f43c/data/rxnclass2name.json)

All 50,000 unbalanced SynRXN Schneider reaction strings exactly match the named RXNFP release in order. The RXNFP NameRxn codes and index dictionary reproduce every SynRXN integer label. All 50,000 balanced reactions exactly match the balanced SynCat source by reaction string, label and split. The two SynCat Schneider variants share the same source row identifiers, label sequence and split. This traces each balanced, transformed reaction to the corresponding unbalanced class. The separately named SynProp file was unavailable in this checkout. The pinned RXNFP and SynCat files establish the mapping independently. [Pinned RXNFP index dictionary](https://github.com/rxn4chemistry/rxnfp/blob/6fd48f4927c2178555cc5d71dbfb225fb178f43c/data/rxnclass2id.json) · [SynRXN curator and source paths](https://github.com/TieuLongPhan/SynRXN/blob/e7c03766bd6a405da468e281d922cf1beccdd56a/script/build_classification_dataset.py)

USPTO-50K uses integer labels 0–9 for literature classes 1–10. Both balanced and unbalanced SynRXN tables match their SynCat parents exactly on all 50,016 rows. Independent canonical reaction matching to the two author releases corroborates the mapping across all ten classes. See [the USPTO-50K audit](uspto50k_label_check.md) for the remaining unmatched and ambiguous rows.
